# word-game

Simple word game I made for my kids to practice phonics/reading.

Live at: https://brianlincoln.github.io/word-game/

## How we use it

I have the youngest say the first letter's name and sound, then have the older one sound out the whole word.

## Settings

The small gear icon in the top-right corner lets you filter the word list by difficulty (all words, just the basics, or trickier words).
